## Como consultar

Baixe o repositório e abra `index.html` no navegador. Mantenha os arquivos e pastas juntos para carregar scripts, imagens e dados. Se o navegador bloquear o carregamento local, execute `python -m http.server 8000` na pasta e acesse `http://localhost:8000`.
